# Spam Mail Prediction using Machine Learning

## Overview

This project classifies emails as Spam or Ham (Not Spam) using Machine Learning. It demonstrates text preprocessing, feature extraction, model training, and prediction using natural language processing techniques.

## Dataset

The dataset contains:

- Email Message
- Label (Spam / Ham)

The model learns from the email text and predicts whether a new message is spam.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Workflow

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Text Preprocessing
5. Feature Extraction using TF-IDF
6. Train-Test Split
7. Model Training
8. Prediction
9. Model Evaluation

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run:

```
Spam_Mail_Prediction_using_machine_learning.ipynb
```

## Results

The model successfully classifies email messages as Spam or Ham using supervised machine learning and natural language processing techniques.
